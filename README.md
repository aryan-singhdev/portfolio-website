## 👨‍💻 About the Project

This is my personal portfolio website created to showcase my **technical skills, projects, certifications, experience, and career interests**.

The website is designed with a modern and responsive interface, focusing on clean presentation, smooth navigation, and a professional user experience.

| Feature | Description |
|---|---|
| 🏠 **Home** | Introduction and personal branding |
| 👤 **About Me** | Educational and professional overview |
| 🏆 **Certificates** | Display of completed certifications |
| 💻 **Projects** | Showcase of personal and academic projects |
| 🛠️ **Skills** | Technical skills and technologies |
